## 🧠 Що таке "магічні константи" і як вони працюють?

Керуюче зусилля на мотор візка розраховується за формулою:

$$u = k_\theta \cdot \theta + k_\omega \cdot \omega + k_x \cdot x + k_v \cdot v$$

Де:
- **$u$** — сила або ШІМ, що подається на мотор (штовхає візок вліво або вправо).
- **$\theta$** (кут нахилу): вимірюється енкодером/потенціометром на осі маятника ($0$ = строго вертикально вгору).
- **$\omega$** (кутова швидкість): швидкість обертання маятника:
  $$\omega \approx \frac{\theta_k - \theta_{k-1}}{\Delta t}$$
- **$v$** (швидкість візка): лінійна швидкість візка з енкодера на колесах або моторі.
- **$x$** (позиція візка): координата вздовж рейки, отримується інтегруванням швидкості:
  $$x_k = x_{k-1} + v_k \cdot \Delta t$$

### Фізичний зміст кожної константи:
| Константа | Назва | Фізичний зміст | Що буде, якщо змінити? |
|---|---|---|---|
| **$k_\theta$** | Посилення за кутом | Визначає, наскільки сильно візок кидається під маятник, якщо той нахилився. | Замало $\to$ не встигає підхопити, маятник падає.<br>Забагато $\to$ візок смикається і вилітає за рейку. |
| **$k_\omega$** | Демпфер кута | Гасить розгойдування маятника (аналог $D$-складової в PID). | Замало $\to$ маятник нескінченно коливається.<br>Забагато $\to$ передемпфування або тремтіння мотора. |
| **$k_x$** | Позиція рейки | Повертає візок до центру рейки ($x = 0$). | Замало $\to$ візок стабілізує маятник, але постійно дрейфує і врізається в край.<br>Забагато $\to$ пріоритет центру важливіший за маятник, маятник впаде. |
| **$k_v$** | Демпфер візка | Гальмує швидкість візка, не даючи йому розігнатися. | Замало $\to$ візок розгойдується по всій рейці.<br>Забагато $\to$ візок повільно реагує на падіння. |

## 🎯 Як розраховуються оптимальні константи (LQR)?

У скрипті реалізовано автоматичний розрахунок за методом **LQR (Linear-Quadratic Regulator)**:
1. Нелінійні рівняння Лагранжа лінеаризуються навколо точки вертикальної рівноваги ($\theta = 0$).
2. Формуються матриці стану $A$ і $B$.
3. За допомогою `scipy.linalg.solve_continuous_are` розв'язується матричне алгебраїчне рівняння Ріккаті для заданих вагових коефіцієнтів $Q$ (пріоритет точності) та $R$ (економія мотора).

Для стандартних параметрів ($M = 1.0$ кг, $m = 0.1$ кг, $L = 1.0$ м):
- **$k_\theta \approx 107.6$**
- **$k_\omega \approx 30.7$**
- **$k_x \approx 10.0$**
- **$k_v \approx 15.7$**

Якщо ваші фізичні розміри інші — просто впишіть ваші $M$, $m$, $L$ у верхній блок файлу [sim.py](file:///home/timlim/Desktop/Code/%D0%9F%D0%9E%D0%9A/double-pendulum-stabilization/sim.py), і скрипт автоматично перерахує нові ідеальні значення.

## 🔌 Готовий код для реального мікроконтролера (Arduino / STM32 / ESP32)

```cpp
// Константи стабілізації (отримані з sim.py):
const float K_THETA = 107.63f;
const float K_OMEGA = 30.74f;
const float K_X     = 10.00f;
const float K_V     = 15.73f;
const float MAX_FORCE = 50.0f; // Максимальний ШІМ або зусилля

float x_pos = 0.0f;
float prev_theta = 0.0f;

void control_loop(float dt) {
    // 1. Зчитування фізичних сенсорів
    float theta = read_pendulum_angle_rad(); // кут у радіанах (0 = строго вгору)
    float v     = read_cart_velocity_mps();  // лінійна швидкість візка в м/с
    
    // 2. Обчислення швидкості зміни кута та поточної позиції
    float omega = (theta - prev_theta) / dt;
    x_pos += v * dt;
    prev_theta = theta;
    
    // 3. Формула стабілізації
    float u = K_THETA * theta + K_OMEGA * omega + K_X * x_pos + K_V * v;
    
    // 4. Обмеження потужності мотора
    if (u > MAX_FORCE)  u = MAX_FORCE;
    if (u < -MAX_FORCE) u = -MAX_FORCE;
    
    // 5. Подача сигналу на драйвер мотора (PWM + DIR)
    set_motor_output(u);
}
```
