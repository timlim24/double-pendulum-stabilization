# Гібридна система стабілізації подвійного інвертованого маятника (MPC Swing-Up + LQR)

Повністю автономний, об'єктно-орієнтований пакет реального часу (Pygame 60 FPS) для керування подвійним перевернутим маятником на рухомому візку (**Double Inverted Pendulum on a Cart — DIP**).

Система об'єднує сильні сторони двох методів:
1. **MPC (Model Predictive Control)**: заздалегідь розрахований оптимальний маневр підйому (Swing-Up) з нижнього нестійкого положення ($\theta_1 \approx 180^\circ, \theta_2 \approx 180^\circ$). Не потребує важких обчислень у реальному часі, запускається користувачем за кнопкою або клавішею `Space`.
2. **LQR (Linear Quadratic Regulator)**: легкий, блискавичний регулятор реального часу для утримання та демпфування маятника у верхній вертикальній точці рівноваги ($\theta_1 = 0^\circ, \theta_2 = 0^\circ$).

## 📁 Структура та ООП-архітектура

Усі файли розміщені в окремій папці `hybrid_mpc_lqr/`. Жоден з існуючих файлів репозиторію не редагувався:

```
hybrid_mpc_lqr/
├── config.py              # Всі фізичні константи, параметри маятника, ліміти та матриці LQR Q/R
├── dynamics.py            # Повні нелінійні рівняння руху Ейлера-Лагранжа та чисельний інтегратор RK4
├── lqr_controller.py      # Лінеаризація, перевірка керованості за Калманом та CARE Riccati розв'язувач
├── mpc_generator.py       # Окремий скрипт розрахунку та збереження оптимального маневру MPC через do-mpc
├── mpc_trajectory.npz     # Попередньо прорахований маневр MPC (час, сили, кути, швидкості)
├── mpc_controller.py      # Плеєр та інтерполятор маневру MPC з перевіркою handover-критерію
├── simulation_manager.py  # Скінченний автомат станів FSM (FALLEN -> MPC_SWINGUP -> LQR_BALANCE)
├── ui.py                  # Графічні компоненти Pygame: Button, Slider, Oscilloscope, ProgressBar
├── main.py                # Головний клас HybridDoublePendulumApp, цикл подій та високоякісний рендеринг
├── run.sh                 # Скрипт швидкого запуску
└── README.md              # Ця документація
```

## ⚙️ Фізичні параметри (`config.py`)

Усі фізичні параметри винесені у виділене місце в класі `SystemConfig` у файлі [config.py](config.py):
- **Маса візка**: $m_0 = 0.6\,\text{кг}$
- **Маси ланок**: $m_1 = 0.2\,\text{кг}, m_2 = 0.2\,\text{кг}$
- **Довжини ланок**: $L_1 = 0.5\,\text{м}, L_2 = 0.5\,\text{м}$
- **Гравітація**: $g = 9.80665\,\text{м/с}^2$
- **Межа рейки**: $X_{\text{rail}} = 1.8\,\text{м}$ (повна довжина $3.6\,\text{м}$)
- **Максимальне зусилля мотора**: $F_{\max} = 35.0\,\text{Н}$
- **Кут захоплення LQR**: $\theta_{\text{catch}} = 24.0^\circ$
- **Кут падіння**: $\theta_{\text{fall}} = 40.0^\circ$

## 🎮 Інтерактивні можливості та керування

### Взаємодія з вагонеткою (візком):
- **Миша (інерційне пружинне захоплення)**: затисніть ліву кнопку миші на візку та тягайте його вліво/вправо. Візок відчуває реальну силу тяги, а маятник — реальну інерцію збурення.
- **Клавіатура**:
  - `◄ Стрілка вліво` / `► Стрілка вправо`: імпульсні поштовхи візка силою, налаштованою на повзунку.
  - `Пробіл`: **активація маневру MPC Swing-Up** (підйом маятника у верхню точку).
  - `M`: увімкнути/вимкнути мотор (вільне коливання).
  - `R`: скинути маятник у нижній стан спокою.
  - `F11` або `F`: перемикання повного екрана.
  - `Esc`: вихід.

### Елементи інтерфейсу (GUI):
- **Кнопка `🚀 MPC Swing-Up`**: запускає відтворення розрахованого фрагмента MPC.
- **Кнопка `⏻ Мотор: УВІМК/ВИМК`**: вимикає привід для перевірки вільного падіння.
- **Кнопка `↻ Скинути вниз`**: скидає візок та маятник у вихідне нижнє положення.
- **Кнопки `⬅ Вліво` / `Вправо ➡`**: поштовхи візка.
- **Слайдери**:
  - `LQR Q_θ`: вага кутового штрафу регулятора LQR.
  - `LQR Q_x`: вага центрирування візка.
  - `F_max`: обмеження максимального зусилля мотора.
  - `Сила поштовху`: амплітуда імпульсу від стрілок.
- **Двоканальний осцилограф**: відображення кутів $\theta_1(t)$ (синій) та $\theta_2(t)$ (помаранчевий) у реальному часі із зеленим коридором стійкості.
- **Індикатор прогресу MPC**: показує поточний відсоток виконання траєкторії підйому перед передачею контролю LQR.

## 🔄 Як перерахувати траєкторію MPC (при зміні фізики)

Якщо ви зміните маси або довжини ланок у [config.py](config.py), ви можете перегенерувати файл траєкторії однією командою:
```bash
./venv/bin/python hybrid_mpc_lqr/mpc_generator.py
```
Це автоматично оновить файл `mpc_trajectory.npz`.
