# 03 — Фізична модель

Модель потрібна в п'яти місцях: оцінювач кута в прошивці, розрахунок LQR,
оптимізація траєкторії підйому, симуляція і SysID. Скрізь вона **однакова**.

## Чому візок «кінематичний»

У підручниках cart-pole моделюють так: на візок діє сила F, він має масу M,
маятник своєю реакцією штовхає візок назад. Для нашого стенду це неправильно.

Кроковий двигун не «штовхає з силою» — він **повертає вал на задану кількість
кроків**. Якщо струму вистачає, візок рухається точно так, як скомандували,
незалежно від маси візка і реакції маятника. Тому:

- **вхід системи — прискорення візка `a`**, яке ми задаємо самі;
- маса візка, тертя візка і сила двигуна в модель **не входять**;
- єдине, що треба знати, — як маятник реагує на рух точки підвісу.

Стара симуляція рахувала саме через силу і масу — тому її коефіцієнти не
переносились на стенд (див. [08](08-history.md)).

## Рівняння маятника

Кут від **нижньої** вертикалі φ:

```
φ'' = − ω0² · sin φ  −  γ · a · cos φ  −  d · φ'  −  c · tanh(φ' / 0.05)
       └─ гравітація ┘   └─ рух візка ─┘   └─ в'язке ┘   └─ сухе тертя ─┘
```

Те саме через кут від **верхньої** вертикалі θ = φ + π (знаки синуса і косинуса міняються):

```
θ'' = ω0² · sin θ  +  γ · a · cos θ  −  d · θ'  −  c · tanh(θ'/0.05)
```

Інтуїція:
- **Гравітація** тягне маятник униз. Біля низу це повертальна сила (коливання),
  біля верху — «відштовхувальна» (маятник падає).
- **Прискорення візка** діє на маятник як «псевдосила» у протилежний бік: різко
  смикнули візок вправо — вантаж відстає вліво. Множник cos φ: найсильніше
  діє, коли маятник вертикальний, і зовсім не діє, коли він горизонтальний.
- **Тертя** в осі енкодера поступово гасить рух.

Привід теж не ідеальний: реальна швидкість візка наздоганяє команду з
постійною часу τ (пружність паса, інерція ротора):

```
v' = (v_команда − v) / τ
```

## Параметри та їхні значення (SysID від 15.11)

| Параметр | Значення | Фізичний зміст |
|---|---|---|
| ω0² | 34.50 (рад/с)² | ω0 = 5.87 рад/с → період власних коливань **1.07 с** |
| γ = κ·ω0²/g | 3.71 1/м | наскільки сильно рух візка розгойдує маятник |
| κ | 1.054 | «підсилення приводу»: візок проходить на 5.4% більше, ніж думає прошивка |
| d | 0.014 1/с | в'язке тертя — дуже мале: амплітуда спадає в e разів за ~140 с |
| c | 0.005 рад/с² | сухе тертя — майже нуль (хороший підшипник енкодера) |
| τ | 2.4 мс | запізнення приводу |

**Звідки γ = ω0²/g.** Для будь-якого жорсткого маятника ω0² = m·g·l/J і
γ = m·l/J, де m — маса, l — відстань до центру мас, J — момент інерції. Тож
γ = ω0²/g завжди, і **маса, довжина та момент інерції окремо не потрібні** —
досить виміряти ω0. Множник κ ловить розбіжність «команда ↔ реальний рух» (у нас
це похибка `STEPS_PER_METER`).

**Еквівалентна довжина.** l_екв = g / ω0² = 28.4 см — такої довжини був би
математичний маятник (точкова маса на невагомій нитці) з тим самим періодом.

## Що ця модель каже про задачу

**Внизу** (φ ≈ 0): `φ'' ≈ −ω0²·φ − γ·a` — звичайний осцилятор, коливання з
періодом 1.07 с. Рухаючи візок, можна підкачувати або забирати енергію.

**Вгорі** (θ ≈ 0): `θ'' ≈ ω0²·θ + γ·a` — **нестійка** система. Без керування
відхилення росте як e^(ω0·t): подвоюється кожні ln2/ω0 ≈ **0.12 с**. Регулятор
має реагувати значно швидше — тому контур працює на 500 Гц (2 мс).

**Енергія маятника** (на одиницю моменту інерції):

```
E = ½·ω² + ω0²·(cos θ − 1)          0 = нерухомо вгорі, −2·ω0² = висить унизу
dE/dt = −γ · a · cos φ · ω          (без тертя)
```

Друга формула — ключ до гасіння коливань: якщо зробити `a = K·ω·cos φ`, то
dE/dt = −γ·K·(ω·cos φ)² ≤ 0 — енергія тільки зменшується. Див. [04](04-control.md#гасіння-коливань-внизу).
