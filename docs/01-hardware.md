# 01 — Залізо

| Вузол | Модель | Роль |

Схема підключення — [`esp32_cart_pole/connections.md`](../esp32_cart_pole/connections.md).

## Піни ESP32

Визначені в [`common/cart_pole_config.h`](../common/cart_pole_config.h), розділ 1.

| Сигнал | GPIO | Примітка |
|---|---|---|
| Енкодер A / B | 16 / 17 | внутрішня підтяжка; краще зовнішня 2.2–4.7 кОм до 3.3 В |
| Лівий / правий стопер | 32 / 33 | 0 = натиснуто |
| STEP (CLK+) | 18 | імпульси кроків; той самий пін читає лічильник кроків |
| DIR (CW+) | 19 | 1 = вправо (+X), 0 = вліво |
| ENABLE (EN+) | 21 | 0 = двигун під струмом |

## Які блоки ESP32 використовуються

- **LEDC** — апаратний генератор ШІМ. Видає імпульси кроку із заданою
  частотою (частота = швидкість візка × кроки на метр). Процесор не витрачає
  час на кожен крок.
- **PCNT** (Pulse Counter) — апаратні лічильники імпульсів. Два:
  1. рахує фронти енкодера маятника (квадратура, ×4);
  2. рахує **власні імпульси STEP** з урахуванням рівня DIR. Тому прошивка
     знає, скільки кроків реально видано, а не лише скільки «просила».
- **FreeRTOS** з тіком 1000 Гц (`CONFIG_FREERTOS_HZ=1000`), щоб контур міг
  працювати на 500 Гц.

## Геометрія рейки

```
 лівий стопер                     центр                     правий стопер
     |<------------------------ 84.5 см ------------------------->|
     |   [візок 4.6 см]                                           |
     |<- хід центру візка: 79.9 см (від -39.95 до +39.95 см) ---->|
```

| Межа (від центру) | Значення | Що відбувається |
|---|---|---|
| Фізичний стопер | ±39.95 см | контакт: X перекалібровується, аварійна зупинка |
| Скасування підйому | ±35 см | підйом перериється, плавна зупинка |
| Межа балансу | ±34 см | швидкість обмежується так, щоб встигнути загальмувати |
| Гасіння внизу, SysID, зона захоплення | ±20 см | |
| Траєкторія підйому | ±15 см фактично (дозволено ±22) | |

Запас ~5 см до стопера — це гальмівний шлях з 0.7 м/с при 5 м/с².

## Калібрування кроку

[`esp32_step_calibration`](../esp32_step_calibration) проїжджає від стопера до
стопера в обидва боки й рахує кроки. Останній результат (15.11):

- 42 111 кроків на хід 79.9 см → **`STEPS_PER_METER = 52704.6`** (19 мкм на крок);
- різниця «вперед/назад» 25 кроків (0.06%) — пропусків кроків і помітного люфту немає.

> **Цікавий момент.** SysID пізніше показав κ = 1.054 — візок рухається на 5.4%
> більше, ніж думає прошивка. 52.7 / 1.054 = 50.0 кроків/мм — кругле число, яке
> дав би, наприклад, мікрокрок 1/8 і шків GT2 на 16 зубів (варто глянути, що
> стоїть). Найімовірніше, реальний хід ≈ 84.2 см, а
> не 79.9 (неточно виміряна відстань між стоперами або ширина візка). На роботу
> це не впливає — SysID врахував різницю через κ. Див. [05 — SysID](05-sysid.md).

## Знаки та одиниці (важливо!)

| Величина | Позначення | Знак / нуль | Одиниці |
|---|---|---|---|
| Положення візка | `x` | 0 = центр, + вправо | м |
| Швидкість візка | `v` | + вправо | м/с |
| Прискорення візка | `a` | + вправо | м/с² |
| Кут від **верхньої** вертикалі | `θ` (theta) | 0 = вгору, ±π = вниз; θ > 0 — вантаж у бік −X | рад |
| Кут від **нижньої** вертикалі | `φ` (phi) | 0 = висить, ±π = вгору | рад |
| Кутова швидкість | `ω` (omega) | dθ/dt = dφ/dt | рад/с |

θ = φ + π (з урахуванням загортання в діапазон (−π, π]).

## Апаратні застереження

- **TB6560 і частота кроків.** За даташитом ≈15 кГц. При 52.7 кроків/мм це лише
  0.28 м/с, а підйому треба до 0.4 м/с (≈21 кГц). Поки SysID не показує пропусків,
  але якщо з'являться — зменшіть мікрокрок удвічі й перекалібруйте.
- **DIR/STEP від 3.3 В** на оптопари драйвера, розраховані на 5 В, — на межі.
- **Люфт паса/шківа** («вал крутиться, візок стоїть») — натяг паса, гвинт шківа на лиску.
- **При ввімкненні маятник має висіти спокійно**: момент старту = нуль енкодера
  (потім нуль сам коригується, див. [04](04-control.md#автокорекція-нуля-енкодера)).
