# Документація проєкту

Перевернутий маятник на візку: ESP32 + кроковий двигун піднімає маятник із
нижнього положення у верхнє і втримує його там. Симуляція на ПК виконує той
самий код, що й плата, тож поводиться як справжній стенд.

## Проєкт за 5 хвилин

**Задача.** На візку, що їздить по рейці, на шарнірі висить стрижень із
вантажем. Візок має розгойдати маятник, підняти його вертикально вгору і
тримати там, рухаючись туди-сюди, — як балансувати олівець на долоні.

**Залізо.** ESP32 керує кроковим двигуном через драйвер TB6560; двигун тягне
візок пасом. Кут маятника міряє оптичний енкодер (2400 позицій на оберт). Два
кінцевики (стопери) на кінцях рейки дають точку відліку.

**Головна ідея коду.** Уся логіка керування — в одному C-файлі
[`common/controller.c`](../common/controller.c). Плата викликає його 500 разів
на секунду. Симулятор на ПК викликає **цей самий** файл (через Python
`ctypes`) разом із моделлю стенду. Тому якщо щось працює в симуляції — воно
працює й на стенді, з точністю до параметрів моделі.

**Параметри моделі** (власна частота маятника, тертя, затримка приводу)
вимірюються автоматично: стенд сам проганяє 3 тестові рухи, скрипт
[`sys_id.py`](../sys_id.py) підбирає параметри, при яких симуляція повторює
запис. Останній запуск: розбіжність між симуляцією і стендом **0.06–0.09°**.

**Як маятник піднімається.** Заздалегідь, на ПК, оптимізатор (CasADi) рахує
найм'якший рух візка, що розгойдує маятник угору за 6 с у межах ±22 см. На
стенді цей рух програється, а регулятор TVLQR щомиті виправляє відхилення
від плану. Вгорі керування переходить до LQR-регулятора балансу.

**Що робить стенд після ввімкнення:**

```mermaid
flowchart LR
    A[Пошук лівого стопера] --> B[Виїзд у центр]
    B --> C[Гасіння коливань]
    C --> D[Очікує команду S]
    D -->|S| E[Підйом 6 с]
    E --> F[Баланс]
    F -->|упав / X| G[Зупинка] --> C
```

**Ключові цифри:**

| Що | Значення |
|---|---|
| Частота контуру керування | 500 Гц |
| Підйом | маятник угорі за ~3.9 с, баланс з ~5.7 с |
| Прискорення / швидкість при підйомі | ≤ 3 м/с² / ≤ 0.4 м/с |
| Точність балансу (симуляція) | кут ±0.07° СКВ, візок ±1 мм СКВ |
| Витримує поштовх маятника | до ~1.5 рад/с |
| Похибка симуляції проти стенду | 0.06–0.09° |
