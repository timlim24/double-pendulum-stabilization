# Автоматичне калібрування фізичного кроку (esp32_step_calibration)

Ця програма призначена для автоматичного апаратного вимірювання точної кількості кроків двигуна на сантиметр/метр вашої рейки.

## Як працює алгоритм:

1. **Перевірка кінцевиків:** перевіряє стан лівого (GPIO 32) та правого (GPIO 33) стоперів.
2. **Прецизійний Homing (Нуль):**
   - Швидкий під'їзд до лівого стопера.
   - Відкат на 500 кроків назад.
   - Повільне мікро-наближення до точки спрацювання (як у промислових ЧПУ/3D-принтерах).
   - Встановлення абсолютної нульової координати (0 кроків).
3. **Проїзд 1 (Зліва направо):**
   - Плавний апаратний розгін.
   - Підрахунок кожного фізичного імпульсу кроку `PUL+` (GPIO 18) аж до спрацювання правого стопера (GPIO 33).
   - Фіксація $N_{\text{forward}}$.
4. **Проїзд 2 (Справа наліво):**
   - Зворотний рух від правого стопера до лівого для верифікації та перевірки на пропуск кроків / люфт.
   - Фіксація $N_{\text{backward}}$.
5. **Математичний розрахунок:**
   - Середнє значення: $N_{\text{avg}} = \frac{N_{\text{forward}} + N_{\text{backward}}}{2}$
   - Кроків на сантиметр: $\frac{N_{\text{avg}}}{63.5\text{ см}}$
   - Кроків на міліметр: $\frac{N_{\text{avg}}}{635.0\text{ мм}}$
   - Кроків на метр: $\frac{N_{\text{avg}}}{0.635\text{ м}}$
   - Дискретність одного кроку в мікронах (мкм).
6. **Повернення в центр:**
   - Візок автоматично виїжджає рівно на $N_{\text{avg}} / 2$ кроків (рівно в центр 31.75 см) і утримує позицію.
7. **Вивід у консоль:**
   - Друкує красиву таблицю з результатами та готовий фрагмент коду `#define STEPS_PER_METER ...` для копіювання в основну програму.
